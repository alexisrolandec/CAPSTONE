Sugerencias:
- Tener instalado Node.js
- Enlace de descarga Node.js: "https://nodejs.org/en"

## Instrucciones de arranque

1. Abrir una terminal posicionada en la carpeta raíz "AgeCare-Administracion-front".

2. Ejecutar el siguiente comando: "npm install" (sin las comillas). Esto instalará las dependencias para levantar nuestro proyecto.

2. Crear archivo con nombre ".env" (sin las comillas) dentro de la carpeta raíz.

3. Ingresar la siguiente variable de entorno, dentro del archivo .env: 
"VITE_API_BASE_URL=http://localhost:8000/api/v1/admin" (sin las comillas)
*Recordar guardar los cambios*

4. Dentro de la terminal activa ejecutamos el siguiente comando: "npm run dev" (sin las comillas)

5. Después de ejecutar el comando anterior se mostrará un link de ingreso a la página web en modo localhost.
